## 1. Налаштування середовища

Для виконання практичної роботи використано Visual Studio Code. Підготовлено середовище для програмування мовою Python та створено репозиторій на GitHub для збереження результатів роботи.

## 2. Перша програма на Python

Для виконання завдання створено файл `my_first_app.py`.

Код програми:

```python
from datetime import datetime

name = "Ilona"
location = "Lviv"

print(f"{name} start programming at {datetime.now()}. {location} is the best city!")
```

Програма використовує модуль `datetime` для отримання поточної дати й часу. Змінна `name` зберігає ім'я, а змінна `location` — назву міста. Команда `print()` виводить повідомлення на екран.

Результат виконання: програма виводить ім'я, поточну дату й час та повідомлення про улюблене місто.

## 3. Робота з Python Notebook

Створено файл `my_first_app.ipynb` для роботи з Python Notebook. У першій комірці розміщено код програми, а в іншій — текст у форматі Markdown із заголовком «Моя перша програма» та описом її роботи.

Notebook дає змогу запускати код у окремих комірках і відразу переглядати результати виконання.

## 4. Використання AI/Copilot

Для прикладу використано програму, яка обчислює суму двох чисел.

Код програми:

```python
a = 5
b = 3

print("Сума =", a + b)
```

Результат виконання:

```text
Сума = 8
```

Пояснення: змінні `a` і `b` містять числа 5 і 3. Оператор `+` виконує додавання, а команда `print()` виводить результат на екран.
