# Лабораторна робота №2

## Тема
Основи Python. Типи даних.

## Мета роботи
Ознайомитися з типами даних Python та навчитися виконувати арифметичні операції зі змінними.

## Хід роботи
Я створила змінні `a` і `b` з числовими значеннями 5 та 2.5. За допомогою оператора додавання обчислила їхню суму. Функцією `type()` визначила типи змінних і результату.

## Результат
Програма виводить два числа, їхні типи даних та суму, яка дорівнює 7.5.

## Висновок
Під час лабораторної роботи я навчилася працювати з типами даних `int` і `float`, виконувати додавання та визначати типи змінних у Python.
