- **Ім'я:** Ілона
- **Навчальний заклад:** IT-коледж

## Як працювати з репозиторієм
1. Відкрити проєкт у Visual Studio Code.
2. Створити або змінити потрібні файли.
3. Зберегти зміни.
4. Відправити зміни на GitHub.

## Майбутні роботи
1. Ознайомлення з Markdown.
2. Створення списків і таблиць.
3. Робота з GitHub.
4. Програмування на Python
